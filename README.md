# frislet: File protocol for flashcards

frislet is a protocol based around ".frislet" files that contain a structure
fit for sharing flashcards. Don't worry about the name.

**What to do with it:** Build clients that can display the info in .frislet archives  
**How it is built:** Review the ["docs" folder.](./docs)
